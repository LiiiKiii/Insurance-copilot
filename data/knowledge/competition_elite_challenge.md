# 年度精英挑戰賽 2026

## 競賽概要

| 項目 | 詳情 |
|------|------|
| 競賽名稱 | 2026年度精英挑戰賽 (Annual Elite Challenge) |
| 主辦單位 | 業務發展部 |
| 競賽期間 | 2026年1月1日 — 2026年9月30日 |
| 公佈結果 | 2026年10月15日 |
| 頒獎典禮 | 2026年11月年度大會 |

## 參賽資格

- 入職滿1年以上的在職持牌代理人
- 上一年度業績達到基本考核標準（年度保費 ≥ 500,000 HKD）
- 無重大合規違規記錄

## 競賽規則

### 綜合積分制

精英挑戰賽採用**多維度綜合積分制**，綜合考量業績和客戶服務：

| 維度 | 權重 | 指標 |
|------|------|------|
| 保費業績 | 50% | 保障保費達成率 |
| 新客開發 | 20% | 新客戶數量 |
| 客戶留存 | 15% | 老客戶續保率 |
| 專業發展 | 15% | 培訓出席率 + AI陪練完成度 |

### 保費目標（按職級）

| 職級 | 目標保費 (HKD) |
|------|---------------|
| 業務主任 | 1,500,000 |
| 業務經理 | 2,800,000 |
| 高級業務經理 | 4,000,000 |
| 區域總監 | 6,000,000 |

### 合資格產品
- 所有個人壽險及健康險產品
- 包含保障型、儲蓄型、投連險
- 團單不計入
- 以核保通過並繳付首期保費為準

## 獎勵方案

### 個人獎
- **全公司前10名**：精英獎章 + 特別花紅（相當於1個月底薪） + 晉升加分（年度考核加5分）
- **全公司前30名**：卓越獎章 + 特別花紅（相當於半個月底薪）
- **達標（100%）**：達標證書 + 精英徽章

### 突破獎
- 較上年同期業績增長 ≥ 50%：突破新星獎 + HKD 15,000
- 較上年同期業績增長 ≥ 100%：超越極限獎 + HKD 30,000

### 團隊獎
- 團隊綜合積分最高的前3組：精英團隊獎盃 + 團隊建設基金 HKD 80,000

## 晉升加分規則

精英挑戰賽成績可作為年度晉升考核的加分項：

| 排名 | 加分 |
|------|------|
| 前10名 | +5分 |
| 前30名 | +3分 |
| 達標 | +1分 |

## 注意事項

1. 積分以季度為單位結算，每季公佈一次排名
2. Q1、Q2、Q3 各季度保費達成率不低於 20% 方有效
3. 競賽期間嚴禁不正當銷售行為
4. 精算部每月5日前更新上月數據
5. 如有爭議，以業務發展部最終裁決為準
